## Обзор проекта

**ZOV Maps** — мобильный геоинформационный комплекс для Android, объединяющий картографию, навигацию и работу с различными типами геопространственных данных. Одной из ключевых особенностей программы является возможность автономной работы с заранее подготовленными картами и другими материалами без постоянного подключения к интернету.

Приложение позволяет использовать топографические, спутниковые, тематические и специальные карты, работать с собственными картографическими источниками и хранить необходимые данные непосредственно на мобильном устройстве. Благодаря этому пользователь может заранее подготовить нужный район и продолжить работу там, где стабильное сетевое подключение отсутствует.

ZOV Maps также предоставляет инструменты для работы со слоями, объектами, маршрутами и координатной информацией. Поддержка распространённых форматов геоданных упрощает перенос подготовленных материалов между программой, навигационными устройствами и другими GIS-инструментами.

## Карты и геоданные

Картографическая система ZOV Maps позволяет объединять разные источники информации в одной рабочей среде. Это могут быть обычные тайловые карты, топографические материалы, спутниковые изображения, тематические слои и данные о рельефе.

Для обмена географической информацией программа поддерживает ряд распространённых форматов. Среди них используются **MBTiles** для тайловых карт, **KML/KMZ** для географических объектов, **GPX** для треков, а также CSV и TXT для списков объектов с координатами.

Поддержка собственных источников позволяет сформировать картографический набор под конкретную задачу. Нужные данные можно подготовить заранее, чтобы впоследствии использовать их автономно без загрузки карт через мобильную сеть.

Программа может использовать данные навигационного модуля мобильного устройства или совместимого внешнего приёмника. Пользователь получает возможность работать с собственным положением, координатами, расстояниями и подготовленными маршрутами непосредственно на карте.

Дополнительно можно использовать локальные адресные базы и матрицы высот. Такой подход позволяет создать на мобильном устройстве полноценный набор геоданных для выбранной территории.
